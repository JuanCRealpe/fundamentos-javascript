1. Condicionales anidados

Las estructuras condicionales permiten tomar decisiones en el código. En JavaScript se usan principalmente con if, else y else if. Un condicional anidado ocurre cuando dentro de un if hay otro if. Esto se usa cuando una decisión depende de otra. Se utilizan en validaciones complejas, por ejemplo:

  • Sistemas de login
  • Validación de pagos
  • Control de permisos de usuario

2. operadores logicos

Los operadores lógicos permiten combinar condiciones:

  • && (AND): ambas condiciones deben cumplirse
  • || (OR): al menos una se cumple
  • ! (NOT): niega una condición

Normalmente se usan para construir validaciones mas complejas como:

  • Formularios
  • Sistemas de acceso
  • Filtros de búsqueda

3. arrays

Un array es una estructura de datos que permite almacenar múltiples valores dentro de una sola variable, organizados por posiciones (índices). Cada elemento tiene una posición que empieza desde 0. tinen uso fundamental en aplicaciones modernas

  • Listas de productos en tiendas online
  • Usuarios en sistemas
  • Datos que vienen de APIs
  • Resultados de búsquedas

se clasifican de la siguiente manera

  • Array simple (de un solo tipo):

    • Contiene elementos similares. ejemplo: precios, cantidades, Id.

    let numeros = [10, 20, 30, 40];

  • Array mixto:

    • Puede contener diferentes tipos de datos. ejemplo: Datos rápidos o pruebas (aunque en producción se usan más objetos)

    let mezcla = ["Juan", 25, true];

  • Array de objetos

    • Es el más usado en desarrollo real y uno de los mas importantes en proyectos. ejemplo: Usuarios de una app, productos de una tienda, datos de una API.

    let usuarios = [{ nombre: "Juan", edad: 25 }];

  • Array multidimensional

    • Es un array dentro de otro array. ejemplo: Tablas de datos, juegos (tablero tipo sudoku o ajedrez).

    let matriz = [[1, 2, 3],[4, 5, 6]];

  • Array vacío

    • Se usa para llenar dinamicamente. ejemplo: Carrito de compras, listas que se llenan con interacción del usuario.

    let carrito = [ ];

4. objetos en javascript

En JavaScript, los objetos son una de las estructuras más importantes. Básicamente, un objeto es una colección de pares clave y valor, donde cada clave (también llamada propiedad) tiene un valor asociado. un objeto es como una “caja” que guarda información organizada y también pueden contener funciones (llamadas métodos). ejemplo: const persona = {nombre: "Ana",edad: 25,ciudad: "Cali"}; a la izquierda podemos ver sus propiedades y a la derecha sus valores

funciones en objetos (metodos)

Son funciones que tú mismo defines como propiedades del objeto.
  • Ejecutan lógica
  • Usan this
  • Manipulan datos

Funciones nativas para objetos

JavaScript tiene funciones ya hechas en su lenguaje para trabajar con objetos (object):
  • keys() → claves
  • values() → valores
  • entries() → pares clave-valor
  • assign() → copiar
  • freeze() → bloquear cambios

5. ciclos en javascript

Un ciclo es una instrucción que repite un conjunto de acciones (también llamados loops), son estructuras de control que permiten ejecutar un bloque de código varias veces mientras se cumpla una condición o para recorrer colecciones de datos como arrays. Son fundamentales para automatizar tareas repetitivas y trabajar con datos dinámicos. Sin ciclos, tendrías que escribir manualmente cada operación repetida. Por ejemplo, si tienes un array con 100 elementos, un ciclo permite recorrerlos automáticamente sin escribir 100 líneas. existen varios tipos:

Tipos principales de ciclos

  • for
    • Se usa cuando sabes cuántas veces quieres repetir algo. Tiene tres partes: Inicialización, condición, incremento
  • while
    • Se ejecuta mientras una condición sea verdadera.
  • for...of
    • Ideal para recorrer arrays directamente.
  • forEach
    • Es un método de los arrays.

    Buenas practicas

  • Evita ciclos infinitos (condiciones que nunca se vuelven falsas)
  • Usa for...of o forEach cuando trabajes con arrays (más limpio)
  • Usa break para salir del ciclo si es necesario
  • Usa continue para saltar una iteración

6. promesas en javascript

En JavaScript, una promesa (Promise) es un objeto que representa la finalización o el fallo eventual de una operación asíncrona. Es decir, sirve para manejar tareas que tardan un tiempo en completarse, como peticiones a una API, lectura de archivos o temporizadores.

Estados de una promesa

  • Pending (pendiente) → todavía no se ha completado.
  • Fulfilled (resuelta) → se completó con éxito.
  • Rejected (rechazada) → ocurrió un error.

tipos de promesas (uso comun)

1.Promesa simple (creada manualmente)

Se usa con new Promise().

2.Promesas utilitarias (métodos de Promise)

  • Promise.all() → espera todas
  • Promise.race() → gana la más rápida
  • Promise.allSettled() → espera todas aunque fallen
  • Promise.any() → la primera que se cumpla

7. funcion fecth

La función fetch() en JavaScript se usa para hacer peticiones HTTP a recursos externos, como APIs o archivos en servidores. Es la forma moderna de obtener datos desde internet dentro del navegador. Permite enviar solicitudes (GET, POST, etc.) y recibir respuestas desde un servidor. ejemplo:

  • Obtener datos de una API
  • Enviar formularios
  • Traer información de una base de datos (a través de un backend)

como funciona?

envia una solicitud al servidor y siempre devuelve una Promesa
  • fetch(url): (url) dirección del recurso API o servidor, envia la solicitud al servidor
  • Recibe una respuesta (Response)
  • .json() convierte los datos a formato JavaScript
  • .then() muestra los datos
  • .catch() captura errores
